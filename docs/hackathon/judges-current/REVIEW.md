## Corrections after lead review

- All three wrongly inferred that "image bytes stay on the device" means no
  network requests. Runtime assets and hosting challenges make requests; no tested
  application path uploaded image bytes. Cloudflare traffic is documented and
  is not evidence of an image upload. Neither guarantees anonymity/privacy.
- Four features plus one intercept are five coefficients, not contradictory
  ranker descriptions. Wording is now explicit in both documents.
- C wrongly says the rejected ranker was evaluated on test/additional images.
  It was evaluated on validation, rejected there, and never promoted to test or
  additional assessment. The graph, not that rejected ranker, appears there.
- "Mask correction" means a human-confirmed alternate label map; no biological
  correctness or observed benefit is claimed. A real mutation can be useful to
  inspect without being proven a better scientific answer.
- Fractional/multiple-tile assignment would alter the frozen metric. Reject that
  recommendation for this assessment; consider only a separately frozen future study.
- A cache cannot eliminate numerical runtime initialization. Do not promise the
  proposed service worker would remove cold latency without measurements.
