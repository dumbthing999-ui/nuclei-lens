## Tracks and categories

- Tracks: Coding and Research.
- Categories: Computer Science + AI (Technology); Biology/Medical and Environmental Science; Math & Physics; Economics; Problem in the Community; Other/Open category.
- Coding track requires a functional prototype/app/site/simulation or other coded solution. Research track requires research documentation; a prototype is optional.

## Required submission fields and deliverables

- A project video link is required; maximum duration four minutes; explain problem, solution, and operation. Demo footage/slides/visuals are permitted.
- A detailed written project description is required. Coding entries should describe technologies; research entries should include background and references where applicable.
- Coding entry must provide a **public** GitHub or other repository containing source code and a README explaining setup/use. A testable live demo is recommended but not required.
- Research entry must upload a PDF using the organizer's requested sections (link is on the official rules page).

## AI and originality

- Previously created projects are allowed but receive a harsh point deduction; rules say create a new original project. Non-original work can be disqualified. Do not reuse an earlier project while claiming it is new.
- AI policy is presented with a wording difference: the Overview says AI for coding/research writing is discouraged but allowed and emphasizes quality; the Rules page says AI development use is permitted. Apply the stricter practical reading: disclose assistance where asked, verify generated work, and make the project independently original and high quality.
- Outside reference/documentation resources are allowed.

## Judging and prizes

- Four equally weighted (25% each) criteria: Innovation & Creativity; Impact & Relevance; Execution & Technical Quality (track-specific); Presentation & Communication.
- Impact & Relevance breaks ties.
- Awards listed: 1st/2nd/3rd in each track, two honorable mentions per category (one per track if not top three), and Best Presentation/Pitch.
- Prize amounts listed on the Overview on retrieval: Coding 1st/2nd/3rd = $1,327/$967/$762; Research 1st/2nd/3rd = $607/$607/$582; 10 honorable mentions = $70 cash each; Best Presentation/Pitch = $70 cash. The page also listed $45 participation credits for up to 300 participants. Sponsor/product values and prize inventory can change; recheck before submission.
- Overview lists a four-minute maximum video; exact prize amount/value may change and should be rechecked if relevant.
