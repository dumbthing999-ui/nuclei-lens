# NucleiLens visual system

Original interlocking-instance/magnifier icon, navy text, scientific blue#2255db,
white panels and gray#f4f6fa background. Mint baseline, amber alternatives and
purple reviewed-mask outlines remain semantically distinct. System sans serif
fonts avoid external font requests. Hero/tagline: See beyond the count.

The social preview uses the actual first BBBC039 training image and actual
baseline outline, with CC0 dataset citation. It is a presentation composition,
not a fabricated product screenshot or a biological accuracy claim. Product
screenshots remain separate under artifacts/screenshots. No video was created.
